# Reproductor_de_Musica_Aurora_sound
Reproductor Web "Aurora Sound"Es una captura de pantalla completa de una aplicación web de un reproductor de música en modo oscuro, ejecutándose localmente en el navegador Edge desde una ruta de archivo (C:/Users/Dell.../reproductor.html).   Interfaz del reproductor: Muestra una estética moderna de streaming tipo Spotify
